## 🛠 Technical Highlights

### Architecture
- **React 18** + TypeScript (type-safe, maintainable)
- **Vite** (fast dev server, 323KB bundle)
- **Tailwind CSS** (utility-first, responsive)
- **Supabase** (PostgreSQL, RLS-enabled)
- **SVG Graphs** (crisp, scalable, interactive)

### Algorithm
**Least Squares Best Approximation:**
```
Score = dot(userVector, activityVector) + budgetBonus + stageBonus
Normalized to 50–100% for display
```

### State Management
- **Hooks-based**: useState for preferences, ranked activities, view
- **Clean separation**: Matcher → Results → Activity flow
- **Emotion-driven**: Mascot emotion state triggers animations

### Animations
- **500ms smooth transitions** on all page changes
- **GPU-accelerated**: Uses transform/opacity, not position/size
- **Duration-aware**: Progress bars scale to level count
- **Emotion-linked**: Mascot animations match interaction context

## 🚀 How to Use

1. **Start the dev server**: `npm run dev` (automatic, handled by system)
2. **Adjust preferences** on the left (sliders, budget, stage)
3. **Click "Find Date"** to run the matching algorithm
4. **View results** with interactive spider graph
5. **Select an activity** to see alternate analysis
6. **Start the date** and go through 4 levels
7. **Upload photos** at each level checkpoint
8. **See heart rain** on completion
9. **View saved data** in Supabase dashboard
